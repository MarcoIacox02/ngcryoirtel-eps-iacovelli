# NG-CryoIRTel EPS Sizing Tool

MATLAB tool for EPS sizing of NG-CryoIRTel cryogenic infrared space telescope.

## Features

- PV array sizing (Marín-Coca method)
- Parametric battery sizing (S3R/S4R trade-off)
- L2 thermal and radiation analysis
- Reliability analysis (99% confidence)
- Automated figure generation
